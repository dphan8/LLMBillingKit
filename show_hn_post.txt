TEXT:
I'm building a SaaS that charges customers per AI feature, and I realized I had no idea which customers were profitable. I was charging flat rates but costs varied wildly depending on model, prompt length, and conversation depth.

So I built LLMBillingKit — a Python package that calculates the net margin of every LLM call. One line of code, local SQLite, no infrastructure.

    from llmbillingkit import track
    response = client.chat.completions.create(model="gpt-4o", messages=[...])
    track(response, charged=0.05, customer="user_123")

Then run `llmbilling report` to see margin by customer, or `llmbilling models` to see which models are eating your budget.

It works with OpenAI, LiteLLM, and anything that returns OpenAI-compatible response objects. Costs are tracked via a bundled pricing table covering ~17 models across OpenAI, Anthropic, Google, and Mistral.

No servers, no Docker, no external dependencies. pip install and go.

Would love feedback on what's missing — especially if you're billing end users for AI features today.
